# 🔍 TruthLens AI
### Know whether an AI answer is still true.

TruthLens AI is an AI-powered application that detects outdated information in AI-generated answers using real-time web search and intelligent fact verification.

## 🚀 Features
- AI-generated claim extraction
- Real-time web search
- Outdated information detection
- Fact verification
- Evidence-based analysis
- Freshness scoring
- Verification reports

## 🛠️ Tech Stack
- React
- TypeScript
- Node.js
- Tavily API
- Bifrost by Maxim AI
- Google AI Studio

## ⚙️ How It Works
1. Enter an AI-generated answer.
2. Extract factual claims.
3. Search for current information.
4. Verify claims using AI.
5. View freshness results and supporting sources.

## 🎯 Purpose
To make AI-generated answers more accurate, current, and trustworthy by identifying potentially outdated information.

## 🔗 Integrations
- **Tavily:** Real-time web search.
- **Bifrost:** AI model gateway and orchestration.
